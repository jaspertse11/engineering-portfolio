## How each project is written up

Each folder has a README covering a summary and my role, key results, how the design works, how the results compared with predictions, what went wrong, and what I would do next. Where code was written with AI assistance, the README says so.

Where I publish code it is in the project's `src/` folder. Some of these were assessed university exercises that later cohorts also do, so for those I publish a design summary and not the code.
