# Flood warning system

**University first-year coding project · Python · Complete**

## Summary

A Python system that works with real river-level data obtained online and predicts future water levels so that an advance flood warning can be given.

## What I learned

The main learning objective was handling datasets: fetching, cleaning and processing real-world measurements. The final stage fitted curves to recent level data to predict where the water level was heading.

## Notes

This is an assessed exercise that later cohorts also do, so I am publishing a design summary and not the code.

## If I did this again

- Evaluate the prediction on historical flood events to measure how much warning time it would really have given.
- Compare different curve-fitting models and report the uncertainty on each prediction.
