# Mars lander

**University first-year project · C++ · Complete**

## Summary

A project for learning C++ by writing control code for a simulated Mars lander, with an introduction to control systems. This is the simple 1D version: a straight descent, with the controller throttling the thrust. The lander lands well.

## What I learned

- The basics of C++.
- An introduction to control systems.

## Notes

This is an assessed exercise that later cohorts also do, so I am publishing a summary and not the code.
